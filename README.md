I'm interested in a simple question: **how much work can a system take off our hands?**

Not just automating individual tasks. I explore ways to connect tools, agents, information, and processes so they can coordinate work, track outcomes, adapt when things change, and need less babysitting.

The aim is to spend less time operating the machinery — and more time deciding what matters.

<sub>Most of this is still a work in progress. The repositories are where I test the ideas.</sub>
